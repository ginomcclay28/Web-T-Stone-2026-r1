What we do

เทคโนโลยีที่ชวนคน
เข้ามาเล่นด้วยกัน

ตั้งแต่ไอเดียแรก ไปจนถึงระบบหน้างานจริง เราดูแลทั้ง Creative, Software, Hardware และ Integration ให้ทำงานเป็นประสบการณ์เดียวกัน

01 / INTERACTIVE✦

Interactive Experience

ออกแบบประสบการณ์ที่ตอบสนองต่อการสัมผัส การเคลื่อนไหว เสียง ภาพ และพฤติกรรมของผู้ชม

 02 / GAMES✺

Games & Gamification

เกมสำหรับบูธ อีเวนต์ แบรนด์ และพื้นที่เรียนรู้ เล่นง่าย สนุก และวัดผลได้

 03 / MUSEUM◉

Museum & Exhibition

สื่อเล่าเรื่องแบบ Immersive, Mapping, Sensor และ Multi-touch

 04 / SYSTEMS⌁

Event Systems

ลงทะเบียน QR code เรียกคิว แจกของรางวัล และระบบข้อมูลหลังบ้าน

 05 / INTEGRATION↗

System Integration

เชื่อม Software, Hardware, Display และ Network ให้พร้อมใช้งานจริงในวันงาน
